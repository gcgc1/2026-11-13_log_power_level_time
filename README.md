# Function
 In windows, this app will log the battery power percentage every 5 seconds.
 
 The results will be saved to a csv file.

I use this app to test the battery life of my laptop (by playing a 1080p video in loop).

  # Sample output data:
 See file: battery_2026-11-13_09_38_26.csv.
